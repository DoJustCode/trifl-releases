# Trifl — руководство

Trifl живёт в строке меню macOS и сам уменьшает размер картинок, GIF, видео, PDF и аудио. Всё работает на вашем Mac, файлы никуда не отправляются.

## Установка и первый запуск
1. Скачайте `Trifl.dmg` со [страницы релизов](../../../releases/latest), перетащите Trifl в «Программы».
2. При первом запуске появится короткое приветствие: выберите, какие папки отслеживать (например «Рабочий стол» или «Загрузки»), и готово.
3. Если macOS спросит доступ к папкам или «Автоматизацию» (для ⌃O в Finder) — разрешите.
4. Обновления приходят сами (Trifl → «Проверить обновления…»).

Требуется macOS 13 или новее, Apple Silicon или Intel.

## Как Trifl сжимает файлы
- **Буфер обмена.** Сделали скриншот или скопировали картинку — в буфере уже сжатая версия.
- **Папки.** Новые файлы в отслеживаемых папках сжимаются автоматически.
- **Перетаскивание.** Бросьте файлы на значок в строке меню, в окно «Зона перетаскивания» или на значок приложения. С зажатым ⌘ при отпускании — сильное сжатие.
- **Finder.** Выделите файлы и нажмите ⌃O, либо используйте меню «Службы» → «Оптимизировать в Trifl».
- **Командная строка и ИИ-агенты** — см. ниже.

Оригинал всегда сохраняется в резервной копии (по умолчанию 7 дней), его можно вернуть кнопкой на карточке результата.

## Карточка результата
После сжатия внизу справа появляется карточка: было → стало, миниатюра и кнопки:
- **Сильное сжатие**, **Для мессенджера** (картинка до 1280 px и ~1,5 МБ, видео 720p до 16 МБ);
- **Уменьшить** (75 / 50 / 25 %);
- **Конвертировать:** WebP, JPEG XL, JPEG, PNG, HEIC, AVIF;
- **Уложить в размер** (500 КБ … 5 МБ);
- **Обрезать** по пропорциям (умная обрезка смещает кадр к главному объекту);
- видео: убрать звук, изменить скорость, сделать GIF;
- **Вернуть оригинал**, **Копировать**, **Показать в Finder**, **Поделиться**, AirDrop, открыть во внешнем редакторе (если задан).

## Меню в строке меню
- Оптимизировать буфер сейчас · сильно · уменьшить вдвое · отменить последнюю оптимизацию · показать последний результат.
- **Игнорировать буфер из <приложение>** — переключает игнор для приложения, которое сейчас активно. Быстрее всего для CorelDRAW, Illustrator, Figma и подобных.
- **Приостановить автоматическую оптимизацию.**
- Следить за буфером / за папками, зона перетаскивания.
- Папка резервных копий, рабочая папка, очистка рабочей папки.
- Проверить обновления, сообщить о проблеме, журнал ошибок, настройки.

## Горячие клавиши
| Клавиши | Действие |
|---|---|
| ⌃⇧C | Оптимизировать буфер |
| ⌃⇧A | Сильное сжатие буфера |
| ⌃⇧− | Уменьшить картинку в буфере вдвое |
| ⌃⇧Z | Отменить последнюю оптимизацию |
| ⌃⇧= | Показать последний результат |
| ⌃O | Оптимизировать выделенное в Finder |

## Настройки
Окно настроек с боковой панелью и поиском.

- **Основное** — качество (максимальное сжатие / сбалансированное / высокое), максимальный размер картинки, заменять файл или сохранять рядом «имя.min», окно результата, уведомления, обновления, запуск при входе.
- **Буфер** — что отслеживать (данные картинки, TIFF, файлы картинок/видео/аудио/PDF), пайплайн для буфера, копирование пути к файлу, список игнорируемых приложений.
  - *Данные TIFF* по умолчанию выключены: так дизайн-редакторы (CorelDRAW и др.) кладут слои.
  - Копию с векторами и слоями Trifl распознаёт сам и не трогает.
- **Папки** — какие папки отслеживать. Для каждой: режим (заменять / копия), качество, максимальный размер, пайплайн, сортировка скриншотов (в папку «Скриншоты», по месяцам или дням), шаблон переименования.
- **Фото и видео** — метаданные (удалять всё / сохранять / сохранять без геометок) и сценарии видео: универсальный (1080p), для мессенджеров (720p до 16 МБ), запись экрана (HEVC), максимальное качество или свои настройки.
- **Фильтры** — для картинок, видео, аудио и PDF: минимальный/максимальный размер, минимальное разрешение, число файлов за раз, расширения, которые не трогать. Фильтры действуют только на автоматическую обработку. Здесь же dpi картинок в PDF.
- **Дополнительно** — адаптивное сжатие, умная обрезка, широкий цвет, потолок fps для видео, битрейт AAC для аудио, Фото.app (лимит и уменьшение), шаблон имени файла из буфера, внешние редакторы, список горячих клавиш.
- **Хранение** — срок хранения резервных копий, рабочая папка, сохранение дат файла, пауза.
- **Пайплайны** — свои цепочки шагов (оптимизировать, уменьшить, конвертировать, обрезать, видео-сценарий, GIF и т. д.), которые можно назначить буферу, перетаскиванию или папке.
- **Инструменты** — установка команды `trifl` и MCP для ИИ-агентов.

## Командная строка
Установите команду на вкладке «Инструменты», затем:

```bash
trifl optimize photo.png
trifl optimize --convert webp --scale 50 photo.jpg
trifl optimize --video messenger recording.mov
trifl optimize --crop 16:9 --copy photo.jpg
```

Основные параметры: `-a` сильное сжатие, `--scale N`, `--convert webp|avif|jxl|jpeg|png|heic`, `--crop W:H`, `--max-size 2MB`, `--mute`, `--speed X`, `--gif`, `--metadata strip|keep|nogps`, `--video universal|messenger|screen|max`, `--video-limit MB`, `--quality low|medium|high`, `--max-dim N`, `--copy`, `--json`.
Работает и в «Быстрых командах» (действие «Выполнить shell-скрипт»).

## ИИ-агенты (MCP)
`trifl mcp` — MCP-сервер (stdio). Подключите его в Claude Desktop, Claude Code или другом клиенте как команду `trifl mcp`, и агент сможет оптимизировать файлы на вашем Mac.

## Если что-то не так
- **CorelDRAW сжимает слои.** Откройте Corel, в меню Trifl включите «Игнорировать буфер из CorelDRAW».
- **Файл не стал меньше.** Значит, он уже оптимален: Trifl не записывает результат, если он не меньше оригинала.
- **Вернуть исходник.** Кнопка «Вернуть оригинал» на карточке, ⌃⇧Z или папка резервных копий.
- **Ошибка или сбой.** Меню → «Сообщить о проблеме…» откроет заявку на GitHub со сведениями о версии и последними строками журнала. Журнал можно посмотреть и отредактировать до отправки.
