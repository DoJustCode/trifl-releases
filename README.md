# Trifl

Приложение для macOS, которое само сжимает картинки, GIF, видео, PDF и аудио. Живёт в строке меню.

## Скачать

**[Trifl.dmg — последняя версия](../../releases/latest)**

Откройте DMG и перетащите Trifl в «Программы». Приложение подписано и нотаризовано Apple. Требуется macOS 13 или новее, работает на Mac с Apple Silicon и Intel.

## Что умеет

- Сжимает скриншоты и картинки в буфере обмена, новые файлы в выбранных папках, а также всё, что вы перетащили на значок или в зону перетаскивания.
- Карточка результата: сильное сжатие, уменьшение, конвертация (JPEG, PNG, HEIC, AVIF, WebP, JPEG XL), кнопка «Для мессенджера», умная обрезка по главному объекту, «уложить в размер», обрезка по пропорциям, возврат оригинала.
- Видео: убрать звук, изменить скорость, обрезать, сделать GIF. В настройках — сценарии (разрешение, HEVC, лимит размера, без звука).
- Метаданные (EXIF, геопозиция): удалить всё, оставить только нужное или не трогать — настраивается.
- Сортировка скриншотов по папкам и шаблон переименования.
- Онбординг при первом запуске, интерфейс на русском и английском.
- Фильтры по размеру, разрешению, расширениям и числу файлов; игнор приложений прямо из меню (удобно для CorelDRAW, Illustrator, Figma); пауза автоматической оптимизации.
- Настройки видео (разрешение, HEVC, ограничение fps, лимит размера), аудио (битрейт AAC), PDF (dpi картинок), Фото.app, внешний редактор результата.
- Горячие клавиши: ⌃⇧C оптимизировать буфер, ⌃⇧A сильное сжатие, ⌃⇧− уменьшить вдвое, ⌃⇧Z отменить последнюю оптимизацию, ⌃⇧= показать последний результат.
- Автообновления: приложение само находит и ставит новые версии (начиная с 1.1).
- Пайплайны из нескольких шагов, отдельные правила для каждой папки, пакетная обработка.
- Команда `trifl` для терминала и MCP-сервер для ИИ-агентов.
- Горячие клавиши: ⌃⇧C оптимизирует буфер, ⌃O оптимизирует выделенное в Finder.
- Всё работает на вашем Mac, файлы никуда не отправляются.

Бесплатно. Версию 1.0 обновите вручную один раз — дальше обновления приходят сами.
